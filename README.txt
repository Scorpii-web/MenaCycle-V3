MENACYCLE 3.0 - ANDROID PROJECT

Ity ZIP ity dia projet Android vonona hapetraka ao amin'ny GitHub mba hanamboarana APK.

Fomba fampiasana:
1. Extract / décompresser ity ZIP ity.
2. Ampidiro ao amin'ny repository GitHub vaovao ny atiny rehetra (tsy ilay dossier MenaCycle_3_0 manontolo).
3. Ataovy branch main.
4. Sokafy ny onglet Actions ao amin'ny GitHub.
5. Safidio "Build MenaCycle APK" ary tsindrio Run workflow, na miandrasa rehefa vita ny push.
6. Rehefa vita ny build, sokafy ny run farany ary alaivo ny artifact "MenaCycle-APK".
7. Extract ilay artifact ary apetraho amin'ny Android ny app-debug.apk.

FAMPITANDREMANA ARA-PAHASALAMANA:
Tombana amin'ny halavan'ny cycle ihany no ataon'ity app ity. Tsy fomba azo antoka hisorohana vohoka ny kajy calendrier. Mety hiova ny ovulation ary mety hitranga ny vohoka na amin'ny andro aseho maitso aza. Ampiasao préservatif na fomba fanabeazana aizana azo antoka raha tsy te ho bevohoka.

- Gradle 8.9
- Android Gradle Plugin 8.7.3
- Java 17
